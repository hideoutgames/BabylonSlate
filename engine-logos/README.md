# Haptic logos

Human-made brand artwork. Copy these files; never generate or redraw them. Platform icons and splash screens are these marks scaled and centred on Haptic's warm black (`#0b0a08`).

| File | Use |
| --- | --- |
| `HapticWordmark-LightMode.png` | Wordmark for light backgrounds (black, blue fringes). |
| `HapticWordmark-DarkMode.png` | Wordmark for dark backgrounds (white, orange fringes). |
| `HapticMark-LightMode.png` | H mark for light backgrounds. |
| `HapticMark-DarkMode.png` | H mark for dark backgrounds. |
| `HapticAppIcon.png` | 1024×1024 opaque app icon (dark H mark on warm black), used for iOS and desktop. |
| `HapticIcon.svg` | haptic.no's favicon tile, for reference. |
