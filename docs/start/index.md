# Get Started

Haptic is a game engine and editor for making 2D and 3D games on the device in front of you. It is designed for iPad first and also runs on iPhone, Android, Mac, Windows, Linux and the web. You build scenes from actors and components, script them with visual node graphs, and export the result as a game that runs in a web browser. Haptic renders with Babylon.js.

## Your first five minutes

1. [Install Haptic](install.md) on your device, or open it in a browser.
2. On the Homepage, choose **New Project**, pick **Basic 3D**, then choose **Create**.
3. In the **Content Browser**, double-tap the **main** scene to open it.
4. Drag in the viewport to look around and pinch to zoom. Tap the Mannequin to select it; the **Inspector** shows its components.
5. Choose **Play** in the toolbar to run the scene, then **Stop** to return.
6. Choose **Save All** (<kbd>Mod</kbd>+<kbd>S</kbd>) to save.
