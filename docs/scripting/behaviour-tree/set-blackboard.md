# Set Blackboard

Writes a value to a Blackboard key and succeeds.

## Settings

| Setting | Default | Description |
| --- | --- | --- |
| Key |  | The Blackboard key to write. The list shows the keys of the Blackboard linked to the tree. |
| Value | true | The value to store. It appears once you pick a key, and its editor matches the key's type. |

## Notes

- With no key chosen, the task does nothing and still succeeds.
