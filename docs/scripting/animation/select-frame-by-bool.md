# Select Frame By Bool

Shows True Frame or False Frame as Active changes.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| True Frame | Frame | The frame while Active is true. |
| False Frame | Frame | The frame while Active is false. |
| Active | Boolean | Which frame to show. Defaults to true. |

## Outputs

| Pin | Type |
| --- | --- |
| Frame | Frame |

## Notes

- Frames switch at once; they do not blend.
