# One Minus

Returns the result of subtracting the input from 1.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- Use it to invert a value between 0 and 1, such as turning [**Normalized Age**](normalized-age.md) into the life remaining.
