# Angle (Degrees)

Returns the current rotation of the particle in degrees.

## Outputs

| Pin | Type |
| --- | --- |
| Angle (Degrees) | Float |

## Notes

- Reads the particle being processed, so it gives no value in **Emit Rate**.
- [**Angle (Radians)**](angle.md) returns the same rotation in radians.
