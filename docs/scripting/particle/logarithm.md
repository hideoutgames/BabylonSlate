# Logarithm

Returns the natural logarithm of the input.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 1 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- **Value** must be greater than 0, otherwise the result is invalid.
