# Cosine (Degrees)

Returns the cosine of an angle in degrees.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- [**Cosine (Radians)**](cosine.md) works in radians.
