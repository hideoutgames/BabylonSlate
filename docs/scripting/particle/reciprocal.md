# Reciprocal

Returns the result of dividing 1 by the input.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 1 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- A **Value** of 0 gives an invalid result.
