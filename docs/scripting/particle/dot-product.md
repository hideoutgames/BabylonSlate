# Dot Product

Returns the dot product of two Vector3 values.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| A | Vector3 | (0, 0, 0) |
| B | Vector3 | (0, 0, 0) |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- For unit vectors the result is 1 when they point the same way, 0 when they are perpendicular and -1 when they are opposite.
