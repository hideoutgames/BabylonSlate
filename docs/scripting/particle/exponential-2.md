# Exponential 2

Returns 2 raised to the power of the input.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
