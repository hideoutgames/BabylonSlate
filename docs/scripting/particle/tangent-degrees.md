# Tangent (Degrees)

Returns the tangent of an angle in degrees.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- [**Tangent (Radians)**](tangent.md) works in radians.
