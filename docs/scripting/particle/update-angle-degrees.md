# Update Angle (Degrees)

Sets the rotation of every particle each frame, in degrees.

| Pin | Type | Description |
| --- | --- | --- |
| Particle | Particle |  |
| Angle | Float (°) | Degrees. |

## Outputs

| Pin | Type |
| --- | --- |
| Particle | Particle |

## Notes
