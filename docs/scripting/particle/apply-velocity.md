# Apply Velocity

Moves every particle along its direction each frame.

## Inputs

| Pin | Type |
| --- | --- |
| Particle | Particle |

## Outputs

| Pin | Type |
| --- | --- |
| Particle | Particle |

## Notes

- Without this node or [**Update Position**](update-position.md), particles never move.
- [**Gravity**](gravity.md) changes a particle's direction, and Apply Velocity turns that direction into movement.
