# Update Scale

Sets the width and height scale of every particle each frame.

## Inputs

| Pin | Type |
| --- | --- |
| Particle | Particle |
| Scale | Vector2 |

## Outputs

| Pin | Type |
| --- | --- |
| Particle | Particle |

## Notes

- A particle is drawn at its size multiplied by its scale.
