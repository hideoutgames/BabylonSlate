# Update Direction

Sets the velocity of every particle each frame.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Particle | Particle |  |
| Direction | Vector 3 | Velocity in metres per second. |

## Outputs

| Pin | Type |
| --- | --- |
| Particle | Particle |

## Notes

- Pair it with [**Apply Velocity**](apply-velocity.md), which moves particles along their direction.
