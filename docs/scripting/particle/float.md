# Float

Returns a fixed number that you set in the **Inspector**.

## Outputs

| Pin | Type |
| --- | --- |
| Value | Float |

## Settings

| Setting | Description |
| --- | --- |
| Value | The number to return. |

## Notes

- Wire one Float into several inputs to change them together.
- Right-click the node, or long-press it, and choose **Convert to Parameter** to let gameplay change the value. The node becomes a [Parameter](parameter.md) node whose default is this value; its wires stay.
