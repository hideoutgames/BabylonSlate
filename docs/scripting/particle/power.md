# Power

Raises a base to the power of an exponent.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Base | Float | 0 |
| Exponent | Float | 1 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Works on Floats only.
- A negative **Base** with a fractional **Exponent** gives an invalid result.
