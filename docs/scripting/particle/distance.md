# Distance

Returns the straight-line distance between two Vector 3 positions.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| A | Vector 3 | (0, 0, 0) |
| B | Vector 3 | (0, 0, 0) |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- For example, wire [**Position**](position.md) and [**Emitter Position**](emitter-position.md) to measure how far a particle is from the emitter.
