# Modulo

Returns the remainder after dividing one Float by another.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| A | Any | 0 |
| B | Any | 1 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- The result has the sign of **A**, and a **B** of 0 gives an invalid result.
