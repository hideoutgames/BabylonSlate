# Vertex Color

Returns the vertex colour painted on the mesh, including alpha.

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| RGBA | Vector4 | Red, green, blue and alpha. |
| RGB | Vector3 | Red, green and blue only. |
| A | Float | Alpha only. |

## Notes

- Only in Surface and Landscape materials.
