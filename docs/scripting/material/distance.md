# Distance

Returns the straight-line distance between two Vector 3 positions.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| A | Any | 0 |
| B | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- For example, wire **Position** and **Emitter Position** to measure how far a particle is from the emitter.
