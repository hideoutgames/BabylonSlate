# Vector 2

Returns a fixed Vector 2 that you set in the **Inspector**.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector 2 |

## Settings

| Setting | Description |
| --- | --- |
| Value | The X and Y values to return. |

## Notes

- In **Add Node**, you can also search for **V2**, **Vec2** or **Float2**.
- Right-click the node, or long-press it, and choose **Convert to Parameter** to expose the value to Material Instances and scripts. The node becomes the parameter of its type holding this value; its wires stay.
