# Step

Returns 0 when a value is below an edge, and 1 otherwise.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Edge | Any | 0 |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector2 or Vector3, but not a Color.
