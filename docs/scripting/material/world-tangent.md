# World Tangent

Returns the surface tangent direction in world space, scaled to a length of 1.

## Outputs

| Pin | Type |
| --- | --- |
| Tangent | Vector3 |

## Notes

- Only in Surface, Landscape and Decal materials. In a Decal material, it follows the decal's local X across the surface.
