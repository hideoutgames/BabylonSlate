# Arctangent 2

Returns the angle in radians of the point (X, Y), measured from the positive X axis.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Y | Any | 0 |
| X | Any | 1 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Unlike [**Arctangent**](arctangent.md), it uses the signs of both inputs to find the quadrant. The result runs from -π to π.
