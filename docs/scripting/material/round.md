# Round

Rounds the input to the nearest whole number.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- Halves round up, so 2.5 becomes 3 and -2.5 becomes -2.
