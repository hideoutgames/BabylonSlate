# Vector3

Returns a fixed Vector3 that you set in the **Inspector**.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector3 |

## Settings

| Setting | Description |
| --- | --- |
| Value | The X, Y and Z values to return. |

## Notes

- In **Add Node**, you can also search for **V3**, **Vec3** or **Float3**.
- Right-click the node, or long-press it, and choose **Convert to Parameter** to expose the value to Material Instances and scripts. The node becomes the parameter of its type holding this value; its wires stay.
