# Mix

Blends from A to B by the amount in Alpha.

## Inputs

| Pin | Type | Default | Description |
| --- | --- | --- | --- |
| A | Any | 0 |  |
| B | Any | 0 |  |
| Alpha | Any | 0 | Blend amount. 0 returns A, 1 returns B, and values outside 0 to 1 extrapolate. |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |
