# Arcsine (Degrees)

Returns the arcsine of the input as an angle in degrees.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- [**Arcsine (Radians)**](arcsine.md) works in radians.
