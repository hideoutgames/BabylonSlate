# Landscape Paint Layers

Returns the paint weight of each of the four landscape paint layers at each point.

## Outputs

| Pin | Type |
| --- | --- |
| Layer 1 | Float |
| Layer 2 | Float |
| Layer 3 | Float |
| Layer 4 | Float |

## Notes

- Weights run from 0 to 1 and add up to 1 at every point.
- Only in Landscape materials.
