# HSL To RGB

Converts hue, saturation and lightness to a colour.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| HSL | Vector3 | (0, 0, 1) |

## Outputs

| Pin | Type |
| --- | --- |
| RGB | Vector3 |

## Notes

- Hue, saturation and lightness each run from 0 to 1.
- The opposite of [**RGB To HSL**](rgb-to-hsl.md).
