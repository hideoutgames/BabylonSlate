# Arctangent (Radians)

Returns the arctangent of the input as an angle in radians.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector2, Vector3 or Color, and works on each component.
