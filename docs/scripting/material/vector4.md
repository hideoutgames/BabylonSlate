# Vector4

Outputs a fixed Vector4 value set in the **Inspector**.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector4 |

## Settings

| Setting | Description |
| --- | --- |
| Value | The X, Y, Z and W components to output. |

## Notes

- The values are used as they are. Use [**Color**](color.md) for a colour picked in display terms.
- In **Add Node**, you can also search for **V4**, **Vec4** or **Float4**.
