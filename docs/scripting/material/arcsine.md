# Arcsine

Returns the arcsine of the input as an angle in radians.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- **Value** must be between -1 and 1, otherwise the result is invalid.
