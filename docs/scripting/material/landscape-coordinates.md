# Landscape Coordinates

Returns texture coordinates from the world X and Z position, for tiling textures across a landscape.

## Inputs

| Pin | Type | Default | Description |
| --- | --- | --- | --- |
| Tiling | Float | 0.1 | Texture repeats per metre: 0.1 repeats a texture every 10 metres. |

## Outputs

| Pin | Type |
| --- | --- |
| UV | Vector 2 |

## Notes

- Only in Landscape materials.
