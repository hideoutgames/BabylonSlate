# Sine (Radians)

Returns the sine of an angle in radians.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Accepts a Float, Vector2, Vector3 or Color, and works on each component.
