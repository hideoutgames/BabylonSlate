# Normalize

Scales a vector to a length of 1 without changing its direction.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- A zero-length vector gives an undefined result.
- A Float input returns -1, 0 or 1.
