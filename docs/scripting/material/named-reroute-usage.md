# Named Reroute Usage

Outputs the value wired into the **Named Reroute** it reads, as if wired straight from that value.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Add one by searching **Add Node** for the Named Reroute's name. It takes that reroute's name and colour.
- **Out** has the type wired into the Named Reroute. With nothing wired there it outputs 0.
- Double-click a usage, or choose **Select Declaration** in its menu, to go to its Named Reroute.
- A usage whose Named Reroute was deleted shows **Missing Reroute** and is an error.
- See [Named Reroutes](../../assets/material.md#named-reroutes).
