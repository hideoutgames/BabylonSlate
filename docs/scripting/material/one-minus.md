# One Minus

Returns 1 minus Value, which turns 0 into 1 and 1 into 0.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| Value | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Use it to invert a mask, such as a [**Fresnel**](fresnel.md) rim or a texture channel.
- A vector is inverted channel by channel.
