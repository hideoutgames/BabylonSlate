# Not Equal

Returns 1 where A differs from B and 0 where it is equal.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| A | Any | 0 |
| B | Any | 0 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Any |

## Notes

- Each channel is compared separately and exactly.
- Connect the result to **Condition** on [**Select**](select.md).
