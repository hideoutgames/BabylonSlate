# Cross Product

Returns the vector perpendicular to both A and B.

## Inputs

| Pin | Type | Default |
| --- | --- | --- |
| A | Vector3 | (0, 0, 0) |
| B | Vector3 | (0, 0, 0) |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector3 |

## Notes

- Swapping A and B reverses the result.
