# Make Array

Builds an array from the item inputs you add.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Array of Wildcard |

## Settings

| Setting | Description |
| --- | --- |
| Items | How many item inputs the node has, from 0 up to 32. |

## Notes

- Items are placed in pin order, with Item 0 first.
- All items share one type, which follows what you connect to them.
