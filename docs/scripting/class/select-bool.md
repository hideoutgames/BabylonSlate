# Select Bool

Returns one of two Boolean values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Boolean |  |
| True | Boolean |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |
