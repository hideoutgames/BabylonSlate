# Set Light Color

Sets the colour of a light.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Target | LightComponent Reference |
| Color | Color |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Uses the red, green and blue channels of **Color**; alpha is ignored.
- Channels are normally between 0 and 1.
