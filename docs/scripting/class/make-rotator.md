# Make Rotator

Builds a rotator from pitch, yaw and roll angles in degrees.

## Inputs

| Pin | Type |
| --- | --- |
| Pitch | Float |
| Yaw | Float |
| Roll | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Rotator |

## Notes

- Pitch turns about the X axis, Yaw about the vertical Y axis and Roll about the Z axis.
