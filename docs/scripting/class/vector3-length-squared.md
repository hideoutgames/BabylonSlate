# Vector3 Length Squared

Returns the length of a vector multiplied by itself.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector 3 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- This is cheaper than [**Vector3 Length**](vector3-length.md), so it suits comparisons such as which vector is longer.
