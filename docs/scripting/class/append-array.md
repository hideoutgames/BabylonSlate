# Append Array

Returns a copy of an array with the items of a second array added to the end.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| In | Exec |  |
| Array | Array of Wildcard |  |
| Other | Array of Wildcard | The array whose items are added after the items of **Array**. |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |
| Out | Array of Wildcard |

## Notes

- The input arrays are not changed. Assign **Out** to a variable to keep the result.
