# Select Transform

Returns one of two Transform values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Transform |  |
| True | Transform |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Transform |
