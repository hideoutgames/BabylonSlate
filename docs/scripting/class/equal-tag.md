# Equal Tag

Returns true when two Tags are the same Tag.

## Inputs

| Pin | Type |
| --- | --- |
| A | Tag |
| B | Tag |

## Outputs

| Pin | Type |
| --- | --- |
| Result | Boolean |

## Notes

- Only the identical Tag is equal; a child Tag does not equal its parent.
- Use [**Matches Tag**](matches-tag.md) to include parent categories.
