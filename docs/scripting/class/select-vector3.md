# Select Vector3

Returns one of two Vector3 values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Vector3 |  |
| True | Vector3 |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector3 |
