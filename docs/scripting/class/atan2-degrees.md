# Atan2 (Degrees)

Returns the angle in degrees of the point (X, Y), measured from the positive X axis.

## Inputs

| Pin | Type |
| --- | --- |
| Y | Float |
| X | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- It uses the signs of both inputs to find the quadrant. The result runs from -180 to 180.
- [**Atan2 (Radians)**](atan2.md) returns the angle in radians.
