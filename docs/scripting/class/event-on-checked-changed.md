# Event On Checked Changed

Runs when a checkbox, radio button or toggle changes its checked state.

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Out | Exec |  |
| Checked | Boolean | True when the control is now checked. |

## Notes

- Choosing a **2D Radio Button** also runs this event on the radio button it unchecks in the same group.
- Belongs to **2D Checkbox**, **2D Radio Button** and **2D Toggle** components.
