# Get Actor Enable Collision

Returns whether an actor's collision is on.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Target | Actor Reference | Left unconnected the pin shows **Self** and uses the actor running the graph. |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Enabled | Boolean | False while [**Set Actor Enable Collision**](set-actor-enable-collision.md) has turned it off. |
