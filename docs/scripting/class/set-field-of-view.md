# Set Field Of View

Sets a camera's field of view in degrees.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Target | CameraComponent Reference |
| FOV | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Only perspective cameras use the field of view. Orthographic cameras use [**Set Orthographic Size**](set-orthographic-size.md) instead.
