# Multiply Vector4

Multiplies two vectors together, component by component.

## Inputs

| Pin | Type |
| --- | --- |
| A | Vector 4 |
| B | Vector 4 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector 4 |

## Notes

- This is not the dot product. Use [**Dot Vector4**](dot-vector4.md) for that.
