# Get Build Number

Returns the build number of the project as a whole number.

## Outputs

| Pin | Type |
| --- | --- |
| Build Number | Integer |

## Notes

- Set the build number in **Project Settings &gt; Export &gt; App Identity**, or turn on **Auto Increment Build Number** there. Play uses the current number; an exported game keeps the number it was packaged with.
