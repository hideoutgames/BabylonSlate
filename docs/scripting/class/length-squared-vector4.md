# Length Squared Vector4

Returns the length of a vector multiplied by itself.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector4 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- This is cheaper than [**Length Vector4**](length-vector4.md), so it suits comparisons such as which vector is longer.
