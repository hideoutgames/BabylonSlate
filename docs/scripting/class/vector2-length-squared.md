# Vector2 Length Squared

Returns the length of a vector multiplied by itself.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector 2 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- This is cheaper than [**Vector2 Length**](vector2-length.md), so it suits comparisons such as which vector is longer.
