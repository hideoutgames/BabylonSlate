# Pad Right

Adds characters after a string until it reaches a length.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| String | String |  |
| Length | Integer | Defaults to 0. |
| Pad Character | String | Defaults to a space. |

## Outputs

| Pin | Type |
| --- | --- |
| Return Value | String |

## Notes

- A string already that long is unchanged. An empty **Pad Character** pads with spaces.
