# Is Touch Device

Returns true when the device has a touch screen.

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Touch Device | Boolean |  |

## Notes

- True on phones and tablets, and on computers with a touch screen.
- Useful for showing on-screen controls, such as a 2D Joystick, only where players can touch them.
