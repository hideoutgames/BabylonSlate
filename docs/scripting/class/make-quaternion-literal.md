# Make Quaternion

Returns a Quaternion value that you enter on the node.

## Inputs

| Pin | Type |
| --- | --- |
| In | Quaternion |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Quaternion |

## Notes

- Another node with the same name builds a Quaternion from separate X, Y, Z and W inputs.
- If **In** is wired, the wired value passes through unchanged.
