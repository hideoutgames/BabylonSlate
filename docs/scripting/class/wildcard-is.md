# Wildcard Is

Returns true when a value's type name matches the given tag.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| In | Any | The value to inspect. Accepts any type. |
| Tag | String | The type name to compare with, such as int, float or vec3. |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Notes

- The comparison is exact and case-sensitive. See [**Wildcard Type Of**](wildcard-type-of.md) for the names.
