# Get Vector Curve Time Range

Returns the times of the Vector Curve's first and last keys.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Curve | Vector Curve |  |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Time Range | Float Range |  |

## Notes

- A curve without keys returns a range from 0 to 0.
- See [Curves and ranges](../curves-and-ranges.md).
