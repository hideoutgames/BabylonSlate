# Truncate

Drops the fraction of a number, rounding toward zero.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Float |  |

## Outputs

| Pin | Type |
| --- | --- |
| Return Value | Integer |

## Notes

- -2.7 becomes -2 and 2.7 becomes 2. Use **Floor** to always round down.
