# Set Capture Only Actors

Sets whether a capture draws only the actors in its list.

## Inputs

| Pin | Type |
| --- | --- |
| Exec | Exec |
| Capture | RenderTargetCapture Reference |
| Only Actors | Boolean |

## Outputs

| Pin | Type |
| --- | --- |
| Then | Exec |

## Notes

- Use [**Set Capture Actors**](set-capture-actors.md) to fill the list. With an empty list, nothing is captured.
