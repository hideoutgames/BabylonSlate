# To String (Vector4)

Converts a Vector4 to text that lists its four values.

## Inputs

| Pin | Type |
| --- | --- |
| In | Vector4 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | String |

## Notes

- Components are listed alphabetically, for example {w: 4, x: 1, y: 2, z: 3}.
