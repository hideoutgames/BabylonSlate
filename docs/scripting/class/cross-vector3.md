# Cross Vector3

Returns a vector perpendicular to both input vectors.

## Inputs

| Pin | Type |
| --- | --- |
| A | Vector3 |
| B | Vector3 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector3 |

## Notes

- Swapping **A** and **B** reverses the result. Parallel vectors give a zero vector.
