# Intersect Tags

Returns a TagContainer with only the Tags found in both TagContainers.

## Inputs

| Pin | Type |
| --- | --- |
| A | TagContainer |
| B | TagContainer |

## Outputs

| Pin | Type |
| --- | --- |
| Result | TagContainer |

## Notes

- Tags are compared exactly; parents and children are not matched.
