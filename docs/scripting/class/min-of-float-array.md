# Min Of Float Array

Returns the smallest number in an array and its index.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Array | Array of Float |  |

## Outputs

| Pin | Type |
| --- | --- |
| Index | Integer |
| Value | Float |

## Notes

- When several items tie, **Index** is the first. An empty array returns Index -1 and Value 0.
