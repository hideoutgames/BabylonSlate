# Get Vector Curve

Returns a copy of the asset's curve as a **Vector Curve** value.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Target | Vector Curve Object |  |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Curve | Vector Curve |  |

## Notes

- Changing the copy does not change the asset.
- Use **Break** on the copy to read its keys.
- See [Curve](../../assets/curve.md).
