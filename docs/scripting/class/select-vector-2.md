# Select Vector 2

Returns one of two Vector 2 values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Vector 2 |  |
| True | Vector 2 |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector 2 |
