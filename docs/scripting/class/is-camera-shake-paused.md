# Is Camera Shake Paused

Returns whether a camera shake is paused.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Handle | CameraShakeHandle | The shake's handle from a Play Camera Shake node. |

## Outputs

| Pin | Type |
| --- | --- |
| Paused | Boolean |

## Notes

- False once the shake has ended.
