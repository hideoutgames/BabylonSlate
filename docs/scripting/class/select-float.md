# Select Float

Returns one of two Float values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Float |  |
| True | Float |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |
