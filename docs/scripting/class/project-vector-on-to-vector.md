# Project Vector On To Vector

Returns the part of a vector that points along another.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Vector | Vector 3 |  |
| Target | Vector 3 |  |

## Outputs

| Pin | Type |
| --- | --- |
| Return Value | Vector 3 |

## Notes

- Returns a zero vector when **Target** is zero.
