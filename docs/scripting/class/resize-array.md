# Resize Array

Returns a copy of an array cut or extended to a size.

| Pin | Type | Description |
| --- | --- | --- |
| In | Exec |  |
| Array | Array of Wildcard |  |
| Size | Integer |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |
| Out | Array of Wildcard |

## Notes
