# Get Capture Only Actors

Returns whether a capture draws only the actors in its list.

## Inputs

| Pin | Type |
| --- | --- |
| Capture | RenderTargetCapture Reference |

## Outputs

| Pin | Type |
| --- | --- |
| Only Actors | Boolean |

## Notes

- When true and the list is empty, nothing is captured.
