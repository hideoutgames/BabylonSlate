# Get Time Range (Vector Curve)

Returns the times of the Vector Curve's first and last keys.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Target | Vector Curve Object |  |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Time Range | Float Range |  |

## Notes

- An empty **Target** or a curve without keys returns 0 to 0.
- See [Curve](../../assets/curve.md).
