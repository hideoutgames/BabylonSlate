# Multiply Color

Multiplies two colours channel by channel.

## Inputs

| Pin | Type |
| --- | --- |
| A | Color |
| B | Color |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Color |

## Notes

- The alpha channel is multiplied too.
- Use it to tint one colour with another.
