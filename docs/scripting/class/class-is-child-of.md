# Class Is Child Of

True when Test Class is Parent Class or one of its child Classes.

## Inputs

| Pin | Type |
| --- | --- |
| Test Class | Class |
| Parent Class | Class |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Notes

- A Class counts as a child of itself.
- [Cast To](cast-to.md) checks an object rather than a Class.
