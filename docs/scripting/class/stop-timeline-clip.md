# Stop Timeline Clip

Stops a Timeline Clip and returns it to its start, or to its end while it plays in reverse.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| In | Exec |  |
| Target | Timeline Clip Reference | The clip, from [Get Scene Timeline Clip](get-scene-timeline-clip.md). |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- The clip shows its values there, so its actors jump back too.
- See [Play clips in the game](../../scenes/timeline.md#play-clips-in-the-game).
