# Fraction

Returns the part of a number after its whole number.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Float |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- The result is from 0 up to 1, also for negative numbers: -1.25 returns 0.75.
