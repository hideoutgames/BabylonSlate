# Select Int

Returns one of two Integer values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Integer |  |
| True | Integer |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Integer |
