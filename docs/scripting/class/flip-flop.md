# Flip Flop

Alternates between two outputs each time it runs, starting with A.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| A | Exec |  |
| B | Exec |  |
| Is A | Boolean | True when this pass ran A, false when it ran B. |

## Notes

- Each object keeps its own state.
