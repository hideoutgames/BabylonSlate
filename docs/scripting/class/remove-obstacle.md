# Remove Obstacle

Removes an obstacle that Add Obstacle placed, making the area walkable again.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| ID | String |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Pass the **ID** that [**Add Obstacle**](add-obstacle.md) returned. An empty or unknown ID does nothing.
