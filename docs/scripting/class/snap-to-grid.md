# Snap To Grid

Rounds a number to the nearest multiple of a grid size.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Float |  |
| Grid Size | Float | Defaults to 1. |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Returns **Value** unchanged when **Grid Size** is 0 or below.
