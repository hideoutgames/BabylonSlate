# Length Squared Vector2

Returns the length of a vector multiplied by itself.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector2 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- This is cheaper than [**Length Vector2**](length-vector2.md), so it suits comparisons such as which vector is longer.
