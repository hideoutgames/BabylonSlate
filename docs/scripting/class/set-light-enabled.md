# Set Light Enabled

Turns a light on or off.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Target | LightComponent Reference |
| Enabled | Boolean |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Only the enabled state changes; the light keeps its colour, intensity and other settings.
