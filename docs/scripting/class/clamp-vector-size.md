# Clamp Vector Size

Keeps a vector's length between a minimum and a maximum.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Vector | Vector 3 |  |
| Min | Float | Defaults to 0. |
| Max | Float | Defaults to 1. |

## Outputs

| Pin | Type |
| --- | --- |
| Return Value | Vector 3 |

## Notes

- The direction does not change. A zero vector stays zero.
