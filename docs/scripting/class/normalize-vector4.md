# Normalize Vector4

Returns the vector scaled to a length of 1, keeping its direction.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector 4 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector 4 |

## Notes

- A vector with a length of almost zero returns (0, 0, 0, 0) instead of an error.
