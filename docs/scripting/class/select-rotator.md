# Select Rotator

Returns one of two Rotator values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Rotator |  |
| True | Rotator |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Rotator |
