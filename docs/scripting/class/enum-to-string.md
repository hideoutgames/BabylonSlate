# Enum to String

Returns the name of an enum member as text.

## Inputs

| Pin | Type |
| --- | --- |
| In | Enum |

## Outputs

| Pin | Type |
| --- | --- |
| Out | String |

## Settings

| Setting | Description |
| --- | --- |
| Enum Type | The enum the node works with. Connecting an enum pin sets it automatically. |

## Notes

- The text is the member name exactly as written in the enum, not the title-cased label shown in menus.
