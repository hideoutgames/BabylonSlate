# Array Clear

Returns an empty array, leaving the input array unchanged.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Array | Array of Wildcard |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |
| Out | Array of Wildcard |

## Notes

- Assign **Out** to a variable to empty the array that variable holds.
