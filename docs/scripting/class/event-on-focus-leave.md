# Event On Focus Leave

Runs when a 2D element loses focus.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Belongs to 2D elements that can take focus: **2D Button**, **2D Focus Target** and interactive controls such as **2D Slider** and **2D Checkbox**.
- Runs before [**Event On Focus Enter**](event-on-focus-enter.md) on the element that takes focus next.
