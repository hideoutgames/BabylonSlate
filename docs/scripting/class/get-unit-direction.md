# Get Unit Direction

Returns the one-unit direction from one point to another.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| From | Vector3 |  |
| To | Vector3 |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector3 |

## Notes

- Returns a zero vector when **From** and **To** are the same point.
