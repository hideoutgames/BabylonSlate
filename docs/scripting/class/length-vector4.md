# Length Vector4

Returns the length of a vector.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector4 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Use [**Length Squared Vector4**](length-squared-vector4.md) when you only compare lengths; it avoids the square root.
