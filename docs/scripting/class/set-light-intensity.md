# Set Light Intensity

Sets how bright a light is.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Target | LightComponent Reference |
| Intensity | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Replaces the Intensity value on the light component.
