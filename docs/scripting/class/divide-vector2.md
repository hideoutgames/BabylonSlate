# Divide Vector2

Divides the first vector by the second, component by component.

## Inputs

| Pin | Type |
| --- | --- |
| A | Vector2 |
| B | Vector2 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector2 |

## Notes

- A component divided by zero gives infinity, or not-a-number when both are zero.
