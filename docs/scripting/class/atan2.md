# Atan2 (Radians)

Returns the angle in radians of the point (X, Y), measured from the positive X axis.

## Inputs

| Pin | Type |
| --- | --- |
| Y | Float |
| X | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- It uses the signs of both inputs to find the quadrant. The result runs from -π to π.
- [**Atan2 (Degrees)**](atan2-degrees.md) returns the angle in degrees.
