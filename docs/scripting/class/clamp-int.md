# Clamp Int

Limits a whole number so that it stays between a minimum and a maximum.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Integer |  |
| Min | Integer | Defaults to 0. |
| Max | Integer | Defaults to 1. |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Integer |

## Notes

- For a Float, use [**Clamp**](clamp.md).
