# Make Transform

Builds a transform from a location, a rotation and an optional scale.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Location | Vector 3 |  |
| Rotation | Rotator |  |
| Scale | Vector 3 | Defaults to 1 on every axis. |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Transform |

## Notes

- The rotation is a rotator in degrees.
