# Select TagContainer

Returns one of two TagContainer values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | TagContainer |  |
| True | TagContainer |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | TagContainer |
