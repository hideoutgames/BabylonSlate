# Modulo Int

Returns the remainder after dividing one whole number by another.

## Inputs

| Pin | Type |
| --- | --- |
| A | Integer |
| B | Integer |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Integer |

## Notes

- The result takes the sign of **A**, so -7 modulo 3 gives -1. A **B** of zero gives 0.
