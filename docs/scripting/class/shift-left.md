# Shift Left

Moves an integer's bits toward the high end.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Integer |  |
| Shift | Integer | Defaults to 1. |

## Outputs

| Pin | Type |
| --- | --- |
| Return Value | Integer |

## Notes

- Each place doubles the value: 3 shifted by 2 is 12.
