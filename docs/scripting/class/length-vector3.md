# Length Vector3

Returns the length of a vector.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector3 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Use [**Length Squared Vector3**](length-squared-vector3.md) when you only compare lengths; it avoids the square root.
