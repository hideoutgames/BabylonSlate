# Map Clear

Returns an empty map, leaving the input map unchanged.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Map | Map of Wildcard to Wildcard |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |
| Out | Map of Wildcard to Wildcard |

## Notes

- Assign **Out** to a variable to empty the map that variable holds.
