# Event On Focus Activate

Runs when the focused 2D element is activated from the keyboard or gamepad.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Fires when the activate input is released while the element still has focus.
- Pointer clicks and taps on a **2D Button** raise [**Event On Click**](event-on-click.md) instead.
