# Starts With

Returns true when a string begins with a given prefix.

## Inputs

| Pin | Type |
| --- | --- |
| In | String |
| Prefix | String |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Notes

- The comparison is case-sensitive.
- An empty **Prefix** always returns true.
