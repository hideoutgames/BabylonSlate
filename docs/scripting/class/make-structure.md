# Make Structure

Builds a structure value from its fields.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Structure |

## Settings

| Setting | Description |
| --- | --- |
| Structure Type | The structure whose fields become the inputs. |

## Notes

- The node has one input for each field of the chosen structure. An unwired input uses the field's default value.
- **Add Node** lists a Make row for each structure in the project.
