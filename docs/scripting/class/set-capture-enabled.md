# Set Capture Enabled

Turns a Render Target Capture actor on or off.

## Inputs

| Pin | Type |
| --- | --- |
| Exec | Exec |
| Capture | RenderTargetCapture Reference |
| Enabled | Boolean |

## Outputs

| Pin | Type |
| --- | --- |
| Then | Exec |

## Notes

- A capture that is not enabled draws nothing, even when it captures every frame.
