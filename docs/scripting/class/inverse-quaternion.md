# Inverse Quaternion

Returns the quaternion that undoes a rotation.

## Inputs

| Pin | Type |
| --- | --- |
| In | Quaternion |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Quaternion |

## Notes

- The result is exact for a normalised quaternion. Use [**Normalize Quaternion**](normalize-quaternion.md) first if the input may not be.
