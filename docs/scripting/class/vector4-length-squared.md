# Vector4 Length Squared

Returns the length of a vector multiplied by itself.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector 4 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- This is cheaper than [**Vector4 Length**](vector4-length.md), so it suits comparisons such as which vector is longer.
