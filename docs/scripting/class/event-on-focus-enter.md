# Event On Focus Enter

Runs when a 2D element gains focus.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Belongs to 2D elements that can take focus: **2D Button**, **2D Focus Target** and interactive controls such as **2D Slider** and **2D Checkbox**. **2D Progress Bar** cannot take focus.
- Focus can move by keyboard, gamepad or by pressing the element.
