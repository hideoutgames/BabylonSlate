# Get Capture Near Clip

Returns the near clip distance of a capture actor's camera.

## Inputs

| Pin | Type |
| --- | --- |
| Capture | RenderTargetCapture Reference |

## Outputs

| Pin | Type |
| --- | --- |
| Near Clip | Float |

## Notes

- Content closer than this distance is not drawn. The distance is in world units.
