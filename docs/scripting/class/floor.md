# Floor

Rounds the input down to the nearest whole number.

## Inputs

| Pin | Type |
| --- | --- |
| In | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- Negative values round away from zero, so -1.5 becomes -2.
