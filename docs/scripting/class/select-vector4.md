# Select Vector4

Returns one of two Vector4 values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Vector4 |  |
| True | Vector4 |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector4 |
