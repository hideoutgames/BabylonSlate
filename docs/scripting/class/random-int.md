# Random Int

Returns a random whole number between **Min** and **Max**.

## Inputs

| Pin | Type |
| --- | --- |
| Min | Integer |
| Max | Integer |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Integer |

## Notes

- Both **Min** and **Max** can be returned. If **Min** is greater than **Max**, the two are swapped.
