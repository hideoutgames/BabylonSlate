# Vector3 Length

Returns the length of a vector.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector 3 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Use [**Vector3 Length Squared**](vector3-length-squared.md) when you only compare lengths; it avoids the square root.
