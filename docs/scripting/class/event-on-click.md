# Event On Click

Runs when a 2D Button is clicked or tapped.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- Fires when a press that began on the button is released while the pointer is still over it; activating a focused button from the keyboard or gamepad also runs it.
- Belongs to a **2D Button** component. Only in Scene Layer Actor classes.
