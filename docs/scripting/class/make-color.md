# Make Color

Builds a colour from red, green, blue and alpha values.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| R | Float |  |
| G | Float |  |
| B | Float |  |
| A | Float | Opacity. When not connected it is 0, which is fully transparent. |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Color |

## Notes

- Channels are normally between 0 (none) and 1 (full).
