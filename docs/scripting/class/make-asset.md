# Make Asset

Returns a reference to an asset that you pick on the node.

## Inputs

| Pin | Type |
| --- | --- |
| In | Asset |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Asset |

## Notes

- The result connects to Asset inputs of any type. If **In** is wired, the wired value passes through unchanged.
