# Break Transform

Splits a transform into its location, rotation and scale.

## Inputs

| Pin | Type |
| --- | --- |
| In | Transform |

## Outputs

| Pin | Type |
| --- | --- |
| Location | Vector3 |
| Rotation | Rotator |
| Scale | Vector3 |

## Notes

- The rotation comes back as a rotator in degrees.
