# Make Enum

Returns a member of an enum that you choose on the node.

## Outputs

| Pin | Type |
| --- | --- |
| Out | Enum |

## Settings

| Setting | Description |
| --- | --- |
| Enum Type | The enum to pick a member from. |
| Value | The member the node returns. |

## Notes

- **Add Node** lists a Make row for each enum in the project.
