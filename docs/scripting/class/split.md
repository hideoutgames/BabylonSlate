# Split

Splits a string into an array of pieces at each separator.

## Inputs

| Pin | Type |
| --- | --- |
| In | String |
| Separator | String |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Array of String |

## Notes

- An empty **Separator** splits the text into single characters.
- If **Separator** is not found, the array holds the whole string as its only item.
