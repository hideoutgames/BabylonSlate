# Rotate Vector

Rotates a vector by a quaternion and returns the result.

## Inputs

| Pin | Type |
| --- | --- |
| Quaternion | Quaternion |
| Vector | Vector3 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector3 |

## Notes

- The quaternion should be normalised.
