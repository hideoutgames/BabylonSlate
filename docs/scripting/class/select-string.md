# Select String

Returns one of two String values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | String |  |
| True | String |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | String |
