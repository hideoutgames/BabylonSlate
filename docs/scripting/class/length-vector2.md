# Length Vector2

Returns the length of a vector.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector2 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Use [**Length Squared Vector2**](length-squared-vector2.md) when you only compare lengths; it avoids the square root.
