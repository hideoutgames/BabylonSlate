# Normalize Axis

Wraps an angle in degrees to between -180 and 180.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Angle | Float |  |

## Outputs

| Pin | Type |
| --- | --- |
| Return Value | Float |

## Notes

- The angle keeps its direction: 190 returns -170.
