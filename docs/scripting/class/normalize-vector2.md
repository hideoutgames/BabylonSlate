# Normalize Vector2

Returns the vector scaled to a length of 1, keeping its direction.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector2 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector2 |

## Notes

- A vector with a length of almost zero returns (0, 0) instead of an error.
