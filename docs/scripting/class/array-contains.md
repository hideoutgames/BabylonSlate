# Array Contains

Returns true when an array holds an item equal to the given item.

## Inputs

| Pin | Type |
| --- | --- |
| Array | Array of Wildcard |
| Item | Wildcard |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Notes

- Vectors, rotators, colours, transforms and structures are compared by their values. Other items must be the same value or the same object.
