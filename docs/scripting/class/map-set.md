# Map Set

Returns a copy of a map with a key set to a value.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Map | Map of Wildcard to Wildcard |
| Key | Wildcard |
| Value | Wildcard |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |
| Out | Map of Wildcard to Wildcard |

## Notes

- An existing key has its value replaced. The input map is not changed.
- Assign **Out** to a variable to keep the result.
