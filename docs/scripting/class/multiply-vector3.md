# Multiply Vector3

Multiplies two vectors together, component by component.

## Inputs

| Pin | Type |
| --- | --- |
| A | Vector3 |
| B | Vector3 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector3 |

## Notes

- This is not the dot product. Use [**Dot Vector3**](dot-vector3.md) for that, or [**Cross Vector3**](cross-vector3.md) for the cross product.
