# Event On Value Changed

Runs when the value of a slider, numeric input or progress bar changes.

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Out | Exec |  |
| Value | Float | The new value. |

## Notes

- Also runs when a script changes the value, for example with **Set Value** or **Increment**.
- Belongs to **2D Slider**, **2D Numeric Input** and **2D Progress Bar** components.
