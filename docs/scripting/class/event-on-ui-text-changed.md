# Event On Text Changed

Runs when the text in a 2D Text Input control changes.

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Out | Exec |  |
| Text | String | The full text after the change. |

## Notes

- Runs for typing and for changes made by a script, such as **Set Text**.
- Belongs to a **2D Text Input** component. Text display components have their own text-changed event.
