# Is Asset Loaded

Returns true when an asset is loaded and ready to use right now.

## Inputs

| Pin | Type |
| --- | --- |
| Asset | Asset |

## Outputs

| Pin | Type |
| --- | --- |
| Loaded | Boolean |

## Notes

- Use [**Get Asset Load State**](get-asset-load-state.md) to tell Loading apart from Failed or Unloaded.
