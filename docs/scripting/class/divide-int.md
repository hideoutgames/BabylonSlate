# Divide Int

Returns the first whole number divided by the second, rounded toward zero.

## Inputs

| Pin | Type |
| --- | --- |
| A | Integer |
| B | Integer |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Integer |

## Notes

- -7 divided by 2 gives -3. A **B** of zero gives 0 instead of an error.
