# Get Scene Layer Camera Zoom

Returns the zoom of a Scene Layer's camera.

## Inputs

| Pin | Type |
| --- | --- |
| Layer | SceneLayer Reference |

## Outputs

| Pin | Type |
| --- | --- |
| Zoom | Float |

## Notes

- It is 1 until a script zooms the camera, and for a layer that has been removed.
