# Set Capture Every Frame

Sets whether a Render Target Capture actor updates every frame.

## Inputs

| Pin | Type |
| --- | --- |
| Exec | Exec |
| Capture | RenderTargetCapture Reference |
| Every Frame | Boolean |

## Outputs

| Pin | Type |
| --- | --- |
| Then | Exec |

## Notes

- Turn it off to update only when [**Capture Render Target**](capture-render-target.md) runs.
