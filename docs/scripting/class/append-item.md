# Append Item

Returns a copy of an array with one item added to the end.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Array | Array of Wildcard |
| Item | Wildcard |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |
| Out | Array of Wildcard |

## Notes

- The input array is not changed. Assign **Out** to a variable to keep the result.
