# Mirror Vector By Normal

Bounces a vector off a surface.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Vector | Vector 3 |  |
| Normal | Vector 3 |  |

## Outputs

| Pin | Type |
| --- | --- |
| Return Value | Vector 3 |

## Notes

- Use the surface's **Normal**, such as a hit's, to bounce a velocity off a wall.
