# Power

Raises a base number to the power of an exponent.

## Inputs

| Pin | Type |
| --- | --- |
| Base | Float |
| Exp | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- A negative base with a fractional exponent has no real result and gives 0, as does 0 raised to a negative exponent.
