# To String (Rotator)

Converts a Rotator to text that lists its pitch, roll and yaw.

## Inputs

| Pin | Type |
| --- | --- |
| In | Rotator |

## Outputs

| Pin | Type |
| --- | --- |
| Out | String |

## Notes

- Values are in degrees, and the text looks like {pitch: 0, roll: 0, yaw: 90}.
