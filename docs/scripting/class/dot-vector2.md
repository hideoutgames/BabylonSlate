# Dot Vector2

Returns the dot product of two vectors.

## Inputs

| Pin | Type |
| --- | --- |
| A | Vector 2 |
| B | Vector 2 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- For two unit-length vectors the result is 1 when they point the same way, 0 when perpendicular and -1 when opposite.
