# Clamp

Limits a value so that it stays between a minimum and a maximum.

## Inputs

| Pin | Type |
| --- | --- |
| Value | Float |
| Min | Float |
| Max | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Accepts a Float, Vector 2 or Vector 3, but not a Color.
- **Min** and **Max** are Floats applied to every component.
