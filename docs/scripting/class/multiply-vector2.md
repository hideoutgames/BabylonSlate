# Multiply Vector2

Multiplies two vectors together, component by component.

## Inputs

| Pin | Type |
| --- | --- |
| A | Vector2 |
| B | Vector2 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Vector2 |

## Notes

- This is not the dot product. Use [**Dot Vector2**](dot-vector2.md) for that.
