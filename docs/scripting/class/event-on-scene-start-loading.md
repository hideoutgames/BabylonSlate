# Event On Scene Start Loading

Runs when the game begins loading a scene.

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Out | Exec |  |
| Scene Name | String | The display name of the scene being loaded. |

## Notes

- Pair it with [**Get Scene Loading Progress**](get-scene-loading-progress.md) to drive a loading screen.
- Only in Game Instance and Game Subsystem classes.
