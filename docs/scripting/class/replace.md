# Replace

Replaces every occurrence of the search text in a string with new text.

## Inputs

| Pin | Type |
| --- | --- |
| In | String |
| Search | String |
| Replacement | String |

## Outputs

| Pin | Type |
| --- | --- |
| Out | String |

## Notes

- Matching is case-sensitive.
- An empty **Search** leaves **In** unchanged.
