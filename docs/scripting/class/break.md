# Break

Leaves the loop it is inside and continues from that loop's Completed output.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |

## Notes

- Works inside [**While Loop**](while-loop.md), [**For Loop With Break**](for-loop-with-break.md), [**For Each With Break**](for-each-with-break.md) and [**For Each Map With Break**](for-each-map-with-break.md). The editor reports a Break placed anywhere else.
- Only the innermost loop is exited.
