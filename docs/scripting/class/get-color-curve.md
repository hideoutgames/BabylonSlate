# Get Color Curve

Returns a copy of the asset's curve as a **Color Curve** value.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Target | Color Curve Object |  |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Curve | Color Curve |  |

## Notes

- Changing the copy does not change the asset.
- Use **Break** on the copy to read its keys.
- See [Curve](../../assets/curve.md).
