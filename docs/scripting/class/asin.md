# Asin (Radians)

Returns the arcsine of the input as an angle in radians.

## Inputs

| Pin | Type |
| --- | --- |
| In | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- An input outside -1 to 1 is read as the nearest of the two.
- [**Asin (Degrees)**](asin-degrees.md) works in degrees.
