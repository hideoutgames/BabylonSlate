# Equal

Returns true when two numbers are exactly equal.

## Inputs

| Pin | Type |
| --- | --- |
| A | Float |
| B | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Notes

- Calculated values can differ by tiny amounts. Use [**Nearly Equal**](nearly-equal.md) to compare those.
