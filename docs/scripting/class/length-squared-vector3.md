# Length Squared Vector3

Returns the length of a vector multiplied by itself.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector3 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- This is cheaper than [**Length Vector3**](length-vector3.md), so it suits comparisons such as which vector is longer.
