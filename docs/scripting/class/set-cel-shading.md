# Set CEL Shading

Changes CEL banding, specular highlights, light mixing and outlines.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Exec | Exec |  |
| Settings | CelShading | Every field of the structure is applied. |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Then | Exec |  |
| Result | ScalabilityResult | Outcome of the request. It stays pending until the renderer confirms the change. |

## Notes

- Project defaults are not changed.
- CEL settings only show when the render mode is CEL.
