# Clamp Float To Range

Returns **Value** limited to the range.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Float |  |
| Range | Float Range |  |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Result | Float |  |

## Notes

- A value inside the range is returned unchanged.
- See [Curves and ranges](../curves-and-ranges.md).
