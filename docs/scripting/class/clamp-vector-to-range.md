# Clamp Vector To Range

Returns **Value** limited to the range, axis by axis.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Vector 3 |  |
| Range | Vector Range |  |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Result | Vector 3 |  |

## Notes

- A value inside the range is returned unchanged.
- See [Curves and ranges](../curves-and-ranges.md).
