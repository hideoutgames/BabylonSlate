# Join

Combines an array of strings into one string with a separator between items.

## Inputs

| Pin | Type |
| --- | --- |
| Array | Array of String |
| Separator | String |

## Outputs

| Pin | Type |
| --- | --- |
| Out | String |

## Notes

- Items appear in array order. An empty array returns an empty string.
