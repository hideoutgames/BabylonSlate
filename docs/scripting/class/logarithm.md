# Logarithm

Returns the logarithm of a number to a chosen base.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Float |  |
| Base | Float | Defaults to 10. |

## Outputs

| Pin | Type |
| --- | --- |
| Return Value | Float |

## Notes

- Returns 0 when **Value** or **Base** is 0 or below, or **Base** is 1.
