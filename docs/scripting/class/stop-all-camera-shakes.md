# Stop All Camera Shakes

Stops every playing camera shake.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| In | Exec |  |
| Immediately | Boolean | Stops them at once instead of blending them out. Off by default. |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |

## Notes

- This includes shakes on Scene Layer views.
