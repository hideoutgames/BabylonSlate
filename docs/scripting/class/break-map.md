# Break Map

Splits a map into an array of keys and an array of values.

## Inputs

| Pin | Type |
| --- | --- |
| Map | Map of Wildcard to Wildcard |

## Outputs

| Pin | Type |
| --- | --- |
| Keys | Array of Wildcard |
| Values | Array of Wildcard |

## Notes

- Both arrays use the same order, so the item at an index in **Values** belongs to the key at that index in **Keys**.
