# Is Integer In Range

Returns true when **Value** lies inside the range.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Value | Integer |  |
| Range | Int Range |  |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Result | Boolean |  |

## Notes

- Both **Min** and **Max** count as inside the range.
- See [Curves and ranges](../curves-and-ranges.md).
