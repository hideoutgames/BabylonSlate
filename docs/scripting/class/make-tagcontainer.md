# Make TagContainer

Returns a TagContainer holding the Tags you select.

## Inputs

| Pin | Type |
| --- | --- |
| Tags | TagContainer |

## Outputs

| Pin | Type |
| --- | --- |
| Tags | TagContainer |

## Notes

- Selecting a category does not include Tags that you add under it later.
- Each Tag is stored once.
