# Vector2 Length

Returns the length of a vector.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector 2 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Use [**Vector2 Length Squared**](vector2-length-squared.md) when you only compare lengths; it avoids the square root.
