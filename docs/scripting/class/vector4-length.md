# Vector4 Length

Returns the length of a vector.

## Inputs

| Pin | Type |
| --- | --- |
| V | Vector 4 |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Use [**Vector4 Length Squared**](vector4-length-squared.md) when you only compare lengths; it avoids the square root.
