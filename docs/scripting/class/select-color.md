# Select Color

Returns one of two Color values, chosen by a Boolean condition.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Index | Boolean | When true, **Out** is the **True** value; otherwise it is the **False** value. |
| False | Color |  |
| True | Color |  |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Color |
