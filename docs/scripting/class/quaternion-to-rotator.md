# Quaternion To Rotator

Converts a quaternion into a rotator in degrees.

## Inputs

| Pin | Type |
| --- | --- |
| In | Quaternion |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Rotator |

## Notes

- Pitch is returned between -90 and 90 degrees.
- Different rotators can describe the same rotation, so the angles may differ from those you started with.
