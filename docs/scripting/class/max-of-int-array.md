# Max Of Int Array

Returns the largest integer in an array and its index.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Array | Array of Integer |  |

## Outputs

| Pin | Type |
| --- | --- |
| Index | Integer |
| Value | Integer |

## Notes

- When several items tie, **Index** is the first. An empty array returns Index -1 and Value 0.
