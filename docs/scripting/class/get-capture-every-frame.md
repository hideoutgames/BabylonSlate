# Get Capture Every Frame

Returns whether a Render Target Capture actor updates every frame.

## Inputs

| Pin | Type |
| --- | --- |
| Capture | RenderTargetCapture Reference |

## Outputs

| Pin | Type |
| --- | --- |
| Every Frame | Boolean |

## Notes

- When false, it updates only when [**Capture Render Target**](capture-render-target.md) runs.
