# Multiply Quaternion

Combines two quaternion rotations into one.

## Inputs

| Pin | Type |
| --- | --- |
| A | Quaternion |
| B | Quaternion |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Quaternion |

## Notes

- Order matters: swapping **A** and **B** generally gives a different rotation.
