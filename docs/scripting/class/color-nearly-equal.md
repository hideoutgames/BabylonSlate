# Color Nearly Equal

Returns true when two colours are equal within a small tolerance.

## Inputs

| Pin | Type |
| --- | --- |
| A | Color |
| B | Color |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Notes

- Each channel, including alpha, may differ by less than 0.000001.
