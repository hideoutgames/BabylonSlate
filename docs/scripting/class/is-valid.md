# Is Valid

Returns true when an object reference points to an object, and false when it is empty.

## Inputs

| Pin | Type |
| --- | --- |
| Object | Object Reference |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Notes

- Use it before reading from a reference that may not be set, such as the result of [**Get Actor Of Class**](get-actor-of-class.md).
