# Nearly Equal

Returns true when two numbers differ by less than a very small amount.

## Inputs

| Pin | Type |
| --- | --- |
| A | Float |
| B | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Notes

- The tolerance is 0.000001. Use it instead of [**Equal**](equal.md) when comparing calculated values.
