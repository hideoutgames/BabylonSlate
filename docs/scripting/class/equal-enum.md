# Equal Enum

Returns true when two enum values are the same member.

## Inputs

| Pin | Type |
| --- | --- |
| A | Enum |
| B | Enum |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Boolean |

## Settings

| Setting | Description |
| --- | --- |
| Enum Type | The enum the node works with. Connecting an enum pin sets it automatically. |
