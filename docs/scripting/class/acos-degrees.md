# Acos (Degrees)

Returns the arccosine of the input as an angle in degrees.

## Inputs

| Pin | Type |
| --- | --- |
| In | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- An input outside -1 to 1 is read as the nearest of the two.
- [**Acos (Radians)**](acos.md) works in radians.
