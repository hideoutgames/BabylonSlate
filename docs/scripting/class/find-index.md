# Find Index

Returns the index of the first item equal to the given item.

## Inputs

| Pin | Type |
| --- | --- |
| Array | Array of Wildcard |
| Item | Wildcard |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Integer |

## Notes

- Returns -1 when no item matches.
- Vectors, rotators, colours, transforms and structures are compared by their values.
