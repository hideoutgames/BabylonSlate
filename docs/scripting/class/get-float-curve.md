# Get Float Curve

Returns a copy of the asset's curve as a **Float Curve** value.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Target | Float Curve Object |  |

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Curve | Float Curve |  |

## Notes

- Changing the copy does not change the asset.
- Use **Break** on the copy to read its keys.
- See [Curve](../../assets/curve.md).
