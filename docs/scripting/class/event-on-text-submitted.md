# Event On Text Submitted

Runs when the player confirms the text in a 2D Text Input control.

## Outputs

| Pin | Type | Description |
| --- | --- | --- |
| Out | Exec |  |
| Text | String | The text at the moment it was confirmed. |

## Notes

- Belongs to a **2D Text Input** component.
