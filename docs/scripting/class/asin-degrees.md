# Asin (Degrees)

Returns the arcsine of the input as an angle in degrees.

## Inputs

| Pin | Type |
| --- | --- |
| In | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- An input outside -1 to 1 is read as the nearest of the two.
- [**Asin (Radians)**](asin.md) works in radians.
