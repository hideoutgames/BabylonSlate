# Array Reverse

Returns a copy of an array with its items in reverse order.

## Inputs

| Pin | Type |
| --- | --- |
| In | Exec |
| Array | Array of Wildcard |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Exec |
| Out | Array of Wildcard |

## Notes

- The input array is not changed. Assign **Out** to a variable to keep the result.
