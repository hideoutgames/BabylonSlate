# To String (Color)

Converts a Color to text that lists its four components.

## Inputs

| Pin | Type |
| --- | --- |
| In | Color |

## Outputs

| Pin | Type |
| --- | --- |
| Out | String |

## Notes

- Components are listed alphabetically as w, x, y and z, which hold alpha, red, green and blue.
