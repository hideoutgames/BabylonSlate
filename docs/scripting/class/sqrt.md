# Sqrt

Returns the square root of the input.

## Inputs

| Pin | Type |
| --- | --- |
| In | Float |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Float |

## Notes

- Accepts a Float, Vector 2, Vector 3 or Color, and works on each component.
- A negative **Value** gives an invalid result.
