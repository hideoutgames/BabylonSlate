# Break Structure

Splits a structure value into its individual fields.

## Inputs

| Pin | Type |
| --- | --- |
| In | Structure |

## Settings

| Setting | Description |
| --- | --- |
| Structure Type | The structure whose fields become the outputs. |

## Notes

- The node has one output for each field of the chosen structure.
- **Add Node** lists a Break row for each structure in the project.
