# Delta Rotator

Returns the rotation that turns one rotator into another.

## Inputs

| Pin | Type |
| --- | --- |
| From | Rotator |
| To | Rotator |

## Outputs

| Pin | Type |
| --- | --- |
| Out | Rotator |

## Notes

- Using [**Combine Rotators**](combine-rotators.md) with **A** set to **From** and **B** set to this result gives **To**.
