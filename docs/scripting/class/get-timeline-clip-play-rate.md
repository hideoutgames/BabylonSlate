# Get Timeline Clip Play Rate

Returns a Timeline Clip's current Play Rate.

## Inputs

| Pin | Type | Description |
| --- | --- | --- |
| Target | Timeline Clip Reference | The clip, from [Get Scene Timeline Clip](get-scene-timeline-clip.md). |

## Outputs

| Pin | Type |
| --- | --- |
| Play Rate | Float |

## Notes

- The clip's **Play Rate** from the editor until **Set Timeline Clip Play Rate** changes it.
- See [Play clips in the game](../../scenes/timeline.md#play-clips-in-the-game).
