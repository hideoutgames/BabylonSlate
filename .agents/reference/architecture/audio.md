# Audio

Imported Audio, mixer/channel routing, spatial attenuation, Play/player playback, baked environmental reverb and occupancy-grid wall muffling.

## Decisions

- One sound type: imported `Audio` (kind `audio`, `source` chunk). Mixer, channel and attenuation are optional user assets; with all refs at None, gain is `assetVolume × playCallVolume`.
- Runtime and graph packages only emit commands; playback lives on the main thread in `AudioService`. No Babylon or Web Audio imports in scripting, BT or runtime.
- Never auto-unlock at load. The first `pointerdown` / `touchstart` on the Play or player canvas unlocks; earlier commands queue (cap 32) and the overlay shows the unlock hint.
- Reverb is one shared parametric bus fed by baked probes; muffling is a DDA walk on the baked occupancy grid. Not triangle ray tracing, Recast or physics rays, and no per-voice convolver.
- Streamed Audio (`playbackMode: "streamed"`, auto-defaulted on import at ≥ 512 KiB) bypasses `AudioBufferCache` PCM decoding (both `playPrepared` and `preload`). `BabylonAudioPlaybackBackend` wraps a managed `HTMLAudioElement` in AudioV2 `CreateStreamingSoundAsync` so gain, spatialization, reverb bus and `_outNode` wall muffling match `StaticSound`, `setVoicePlaybackRate` drives `element.playbackRate` (`preservesPitch = false`), and `stop`/`dispose` clear `src` and call `load()` to release WebKit decoders. In Editor Play, `AudioService` ref-counts Blob URLs (dropping lazily-loaded `sourceBytes` after preload or Blob creation and revoking URLs when the last voice stops); exported builds emit content-hashed `assets/stream-*` sidecars (`streamClips` and `streamRevisions` in `game.json`) with metadata-only `HPAU` envelopes so the player streams directly by URL when `baseUrl` is present and verifies digests on memory/file fallback.
- Out of scope: mic capture, acoustic zones/materials, triangle occlusion, waveform editing, DSP plugins, IR convolution.

## Formats

- **Audio**: `volume` 0..1 (1), `loop` (false), `playbackMode` (`"decoded"` | `"streamed"`, default `"decoded"`; imports ≥ `AUDIO_AUTO_STREAM_MIN_BYTES` default to `"streamed"`), `audioChannelGuid` / `soundAttenuationGuid` (null), `clips` (default one `source` clip, cap 8; extra files are `source:<id>` chunks, not other Audio guids; `source` cannot be removed), `pitch` 0.25..4, `pitchRandom`, `pitchMin` / `pitchMax`.
- **AudioChannel** (`.channel.hasset`): no volume; `parentChannelGuid`, `effects` of `environmentReverb` / `muffleThroughWalls`. Keep both effect kinds when editing. Parent cycles fail validation; missing parents route to master.
- **AudioMixer** (`.mixer.hasset`): user asset, not a singleton; `globalVolume`, `channels: { channelGuid, volume }[]` (unique guids).
- **SoundAttenuation** (`.atten.hasset`): opts into 3D (`null` = non-spatial); radii, distance model, rolloff, spatialisation, optional cone and Doppler.
- Project Settings `audio`: `audioMixerGuid`, `occlusionEnabled`, reverb wet/decay/damping scales (0..2).
- Header `dependencies[]` list channel, attenuation, parent and mixer channels for references and delete guards.
- Scene `audioReverb` chunk: magic `HPAR`, a format word (`1`; decode reads no field from a chunk with any other value), flags, geometry hash, probes and the occupancy bitmap, ≤ 64 KiB. Export sidecar `audioReverb:<sceneGuid>`. Packed Audio uses an `HPAU` envelope (`audio-payload.ts`): magic, `u16 version` (1), `u16 flags` (0), `u32` JSON length, the payload JSON, `u32 clipCount`, then each clip as `u32` length and bytes; the reader never guesses between one clip and several, and refuses any other version, unknown flags, truncation or trailing bytes. Exported streamed Audio writes raw clip sidecars (`assets/stream-*.<ext>`, indexed by `streamClips` on the manifest entry) alongside a metadata-only `HPAU` envelope.

## Gain and commands

- `outputGain = assetVolume × playCallVolume × channelGain × parentGains… × globalGain`, each clamped 0..1. Channel-less sounds never take channel gain or effects.
- Set Channel / Set Global Volume replace session values only and require a selected mixer containing the channel (`audio.no_mixer` / `audio.unknown_channel`). Stop or scene change reloads mixer defaults.
- Worker → main ([bridge.md](bridge.md)): `playSound`, `stopSound`, `setVoiceGain`, `setVoicePitch`, `setVoicePaused`, `setChannelVolume`, `setGlobalVolume`. `setVoicePaused` is the game pause (`GamePauseVoices`, [`runtime-game-pause.ts`](../../../packages/runtime/src/runtime-game-pause.ts)): when Set Game Paused applies, every live voice whose emitter guid (the actor, component, Game Instance or Scene Layer that played it) does not tick on pause is held, as is each such voice that starts while paused; all are released when the pause ends. `AudioPlaybackBackend.setVoicePaused` keeps a held voice paused through a whole-backend `setPaused(false)` and pauses a held voice as it starts; `stop` drops the hold, so a stopped voice id played again starts unpaused. Main → worker: `audioVoiceEnded` when a non-looping voice plays to its end → Event On Audio Finished; and with `dropped` when a named voice never started (missing or failed source, stopped while loading with no later play waiting) or was stolen at the voice cap, which only clears the runtime's live voice (`RuntimeVoices`), so Is Sound Playing reads false and no event runs. `RuntimeVoices` (and `RuntimeParticles`) forget every voice (component) at each `activeScene` whose `sceneLoadId` differs from the last, the same Scene loaded again included, as the hosts reset their audio and particle sessions for every Scene load after the boot Scene's.
- Voice cap (`audioMaxVoices`): a play over the cap, or `setMaxVoices` below the live count, cuts the least audible voice (`leastAudibleVoice` in `audio-service.ts`), the incoming one included: every spatial voice before any non-spatial one (music and UI are kept), then the lowest `gain × attenuation` (the distance gain playback applies at the current listener), then a one-shot before a looping voice, then the oldest. A stolen voice is reported `dropped`; an incoming voice that loses is released before it starts and reported `dropped` by the play's settle, like any voice that never starts. Silent voices (beyond Max Radius) keep playing; there are no virtual voices.
- Loop when `command.loop` or `payload.loop`. Graph and BT Play Sound omit `loop`; `AudioComponent.loop` forces it. A looping voice is one Babylon voice; never retrigger it per tick.
- Voice ids: component guid (AudioComponent), `script:<n>` (graph Play Sound), `bt:${actor.guid}:${node.id}` (BT). Replaying an id stops the previous voice.
- `clipRoll` / `pitchRoll` come from a seeded per-session stream, so a run with the same seed plays the same clip and pitch, and trace frames record them.
- Two pauses: the backend-wide `setPaused` (user pause, hidden page, interruptions; see Preview and lifecycle) and the per-voice game-pause hold (`setVoicePaused`, above). Nothing else pauses a single voice.
- Sound Handles (`engine:SoundHandle` `{ Id }`): script Play Sound / Play Sound At Location voices are `script:<Id>` (`RuntimeVoices.scriptVoiceId`), so a handle names its voice; handle nodes act only on voices `RuntimeVoices` still holds live. `playSound.location` gives a voice a fixed pose used instead of its emitter's (the emitter guid stays for game pause; no emitter slot is posed for it, and a located spatial voice is not `audio.missing_emitter`). `playSound.pitch` and `setVoicePitch` set the play-call multiplier (0.25..4) on the asset's pitch draw; Doppler composes on top. Fades live in the worker: `RuntimeVoices.fade` ramps the play-call volume with a `setVoiceGain` per tick from `advance` (real time, like voice age), Fade Out ends with `stopSound`, and Set Sound Volume is a zero-length fade that cancels any other.

## Spatial

- The worker sends identity only; the main thread follows applied snapshot poses (with quaternion for cones). Only emitters of live spatial voices are posed; with none, the render loop skips spatial sync.
- Listener = `scene.activeCamera` after snapshot apply. No listener picker or second listener actor.
- Distance falloff is `computeAttenuationGain` ([`audio-payload.ts`](../../../packages/assets/src/audio-payload.ts)), the curve the Sound Attenuation editor plots: 1 within Inner Radius, 0 at and beyond Max Radius for every model. `AudioService` computes it for each spatial voice from where its panner is (the emitter pose; a pose-less voice holds its last landed pose, else the origin) to the listener, on every placement and listener move, and sends it with `setVoiceAttenuation` (only when it changes). A voice starts at the gain of its first placement (`AudioPlayRequest.attenuation`), so it never plays a frame at full volume. The backend multiplies it with the voice's gain and muffle into the AudioV2 volume, which ramps every write over the engine's parameter ramp (10 ms), so per-snapshot changes do not click; it scales the dry route, the muffle send and the reverb bus alike. The panner only pans and aims cones: linear model with rolloff 0, so the browser's distance models (whose inverse and exponential curves ignore the maximum distance) are 1. Distance gain never goes through `setVoiceGain`, which stays the mixer and play-call gain.
- No AudioV2 auto-update loops: spatial voices are created with `spatialAutoUpdate: false` and the engine with `listenerAutoUpdate: false`, and `setVoicePose` / `setListenerPose` write the pose in place and call `update()`, which pushes it to the panner or AudioContext listener at once. A non-spatial voice passes no spatial option at all, since any one makes AudioV2 give the sound a panner.
- Doppler is applied as `playbackRate` from radial velocity × factor, composed with pitch; a listener-only refresh must not rewrite it.
- `AudioService` sends the backend a listener pose, a voice's pose, distance gain, muffle and playback rate, and the reverb profile only when the value differs from the last one the backend took; those backend setters return whether the write landed (false without an engine, the voice or a muffle route), and a write that did not land is offered again on the next refresh. A voice's occlusion factor is traced again only when its emitter position, the listener position or the occupancy grid changed, and the reverb profile is interpolated again only when the listener position, the reverb field or whether any voice sends to it changed. Every write of these values goes through the service's `sendVoice…` methods, `applyListener` and `refreshReverbWet`; a decoded reverb field is never edited in place.

## Reverb bake

- Like nav bake: main-thread collect of static `MeshComponent` triangles (8 actors per yield), worker occupancy + flood fill + probes, 1,500 ms debounce, 8,000 ms timeout, geometry-hash cache.
- Each bake runs in its own worker, terminated when it settles, times out or is superseded. At most `bakeSlots` bakes run at once, background and flush alike (the editor passes cores − 1, at least 1), and a bake's timeout starts when it takes a slot, so it covers only that bake's own work, never time spent queued. A flush registers every Scene at once, so an edit made during it waits and bakes afterwards. Trade-off: a flush of more Scenes than slots can take up to ⌈Scenes / slots⌉ timeouts while holding Save's lane and write admission. Background bakes likewise hold write admission from collect through write, including while they wait for a slot, so a Simulation Play start's write lock (its lease `ready`) waits for every already-admitted bake: up to ⌈admitted bakes / slots⌉ timeouts plus collect and write time. A debounce that fires after the lock is refused admission and adds nothing.
- Background bakes never save authored edits; results for unsaved geometry stay staged in `ProjectService` until Save writes geometry and chunk together. A flush (Save, export) is never superseded.
- Save removes a stale reverb chunk when geometry changed without a matching result. Export packs only saved results; a reached Scene whose result could not be saved fails export.
- Do not `disconnect()` AudioV2 private `_outNode` / `_inNode` ports (it hung Play Stop); remove only the reverb graph's own edges.

## Budgets

Named constants in [`audio-payload.ts`](../../../packages/assets/src/audio-payload.ts): occupancy grid ≤ 24×24×16, voxel 2 units, 32 probes, 1 reverb bus with 4 comb / 2 all-pass taps, 32 queued pre-unlock commands, 256 MiB decoded PCM LRU (Engine Settings `audioByteCeiling`), 256 KiB per-voice streamed buffer estimate (`AUDIO_STREAMED_VOICE_ESTIMATE_BYTES`), 512 KiB auto-stream import threshold (`AUDIO_AUTO_STREAM_MIN_BYTES`), 32 voices default (`audioMaxVoices`, 8–128), 8 clips per Audio. Streamed voices are tracked in `audioStats.streamedVoices` / `audioStats.streamedBytes` (included in `audioStats.accountedBytes`) without consuming the decoded PCM LRU. Muffle constants (700 Hz low-pass, saturates after 2 walls) live in [`audio-reverb.ts`](../../../packages/assets/src/audio-reverb.ts); 128 waveform bars in [`audio-waveform.ts`](../../../packages/assets/src/audio-waveform.ts).

## Preview and lifecycle

- Asset preview prefetches clip bytes on open and starts playback in the same turn as the Play click; WKWebView drops the gesture if Play awaits I/O.
- Play and previews share `attachAudioLifecycle`: user pause, hidden page, native inactivity and interruptions are independent pause sources; Babylon's automatic resume timer is disabled.
- Overlay Play and the player load Audio metadata at session start and clip chunks (or direct stream URLs) on first `playSound`.
