# Asking the user

Use the Ask Question tool (`AskUserQuestion` in Claude Code, or the host's equivalent) when you have questions or need input from the user: a decision, a choice between options, or approval of a design or plan.

- Give concrete options with the recommended one first, and make each question self-contained: the user may see only the dialog.
- Show a design or mockup before asking for its approval. When the user asks to see a design first, wait for their approval before implementing it.
- Do not ask what the request, the code or the repository's conventions already answer.
- Other channels stay available where they fit better, such as notifications or review requests.
